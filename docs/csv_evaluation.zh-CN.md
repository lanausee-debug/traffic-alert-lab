# 导入自己的 CSV，评测交通告警

[English / 精确定义](csv_evaluation.md) · [真正训练的小教程](tiny_training.zh-CN.md)

只需要 Python 3.12，**不需要安装 PyTorch 或下载交通数据**。已有模型输出风险分数，就能直接评测。

```bash
python alert_eval.py examples/synthetic_alerts.csv --threshold 0.5 --synthetic --output runs/example-report
```

打开新目录中的 `report.html` 看报告。`report.json` 保存完整事件配对、逐次告警分类、排除记录及输入文件 SHA。合成示例有两个事件：一个提前15分钟发现，一个漏报，另有一次误报；不代表实际交通性能。

自己的文件使用同一条命令替换 CSV 路径，并去掉 `--synthetic`。每次使用新的输出目录，避免覆盖旧报告。

## 准备四列

| 列名 | 内容 |
| --- | --- |
| `station_id` | 站点编号，不能为空 |
| `timestamp` | **分数可以用于决策的时刻**，例如 `2020-01-01T08:00:00+08:00`；必须带时区 |
| `score` | 模型分数，0到1；空白表示没有输出 |
| `is_event` | 该时刻的评测真值，0为非事件、1为事件、空白为未知 |

事件真值只能用于训练目标或离线评测，不能作为预测输入。预测目标时刻和分数可用时刻有区别，不能把较晚获得的预测回填到更早时刻。阈值必须先在独立校准集选好；本工具不会替你在测试集挑最优阈值。

默认每5分钟一个点，关联窗口15分钟，要求提前10分钟：

```bash
python alert_eval.py my_scores.csv --step-minutes 5 --horizon-minutes 15 --early-minutes 10 --threshold 0.5 --output runs/my-report
```

## 怎样计算

- 连续的1构成事件；必须有已知0包围，并且事件前后都有完整窗口。靠近数据边界、缺口或未知标签的歧义事件会排除。
- 超阈值的连续区间只算一次告警。一个告警只能归属最早兼容的事件；重复告警单独计数，不能多算发现事件。持续报警也不能自动命中后续事件。
- 检出率包含迟报；提前召回另外要求达到指定提前量；误报按告警次数除以有效决策站日。三个指标需要一起看。
- 提前量直接用“事件起点减告警时刻”，允许负值表示迟报。未知分数不插值；缺口、未知真值与无完整未来窗口的决策不冒充有效负样本。
- 缺失分数后，首段高分无法确定真正起点，会排除直到出现已知低分。有效决策曝光仍包含缺分数时刻，避免把未输出当成系统正常工作。
- 分母为零时返回 `null`；报告展示排除数量。完整定义、事件所有权和站日计算见[英文协议](csv_evaluation.md)。

**它与论文冻结评测是两个协议。** 论文使用的代理提前量含一个步长偏移，边界筛选及有效站日也不同。不能用本工具重写原论文结果表；这个通用入口用于接入其他人的模型结果。

目前不提供统计置信区间，不自动审计数据拆分来源，也没有实际拥堵真值核验。合成示例和模型输出格式已公开，原始交通数据、真实逐站窗口与权重仍不分发。
