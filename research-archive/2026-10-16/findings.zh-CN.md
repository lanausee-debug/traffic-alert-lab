# 历史实验结论与失败边界

原论文联合主检验未通过。以下是既有研究记录的归档摘要，不是新实验，也未重新声明独立确认。

| 方向 | 保留结论 |
| --- | --- |
| 原PEMS-BAY告警模型 | 相对一个基线的R10区间下界未超过0，联合主检验失败；不改写为成功。 |
| 召回修复、锚定风险修正 | 开发改善未形成可靠跨站优势；跨站固定门槛未通过。 |

| 起点可分性 | 条件分类表现不等于完整告警策略改善；中间开发块AP条件未满足。 |
| 冻结探针迁移诊断 | 某些排序指标改善，但固定阈值不能保持早预警；不作确认性优势。 |
| 早预警保护与低速豁免 | 原R10部分保持，但有效迟报检出损失及误报减少条件仍不满足。 |
| 纳入迟报正例 | 校准检出部分恢复，误报仅降约5.88%，短块损失超限，联合条件仍失败。 |
| 事件与提前量定义 | 一次30.1mph越线可形成新的低速代理事件；R15参考最后历史观测时间，不是现场首次拥堵前15分钟。 |
| 两次连续恢复敏感性 | 一个被保护的重入事件并入更早已检出的过程；该独立预警收益依赖定义。 |
| 首段/重入归因 | 验证豁免救回的是重入子段，过滤的检出损失在父过程第一子段；重新标记误报为重复并不会减少实际告警片段。 |

较早METR-LA和传感器修复试验亦保留代码与聚合记录。有些工程核查或描述指标通过，但不能把它们当成已通过交通性能主检验。三种缺失情景共享事件，开发时段反复使用，校准半块重叠；不能当作独立样本重复计数。

归档用途是保留可审查的失败证据和代码演进。后续应单独检验仅作用于通知发送层的去重方法，并约束首次告警身份与提前量；此归档没有声称该方案已经实现或通过验证。

## 范围与恢复

同目录ZIP包含代码、测试、研究协议、旧源文件版本和35个阶段的聚合结果；archive-manifest.json列出每个文件字节数与SHA256。原始数据、训练权重、样本/逐事件缓存及论文Word/PPT没有公开。它不是26个旧ZIP的完整镜像。

删除的只是已经去重、可被当前活动项目及本公开源文件归档覆盖的历史实验ZIP。当前本地原始数据、模型和工作结果保留。归档代码中的旧ZIP保存/恢复脚本仅供历史审查；用户已取消今后每轮本地ZIP备份，不应自动继续执行这些历史保存脚本。
