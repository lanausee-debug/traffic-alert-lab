# PEMS-BAY风险层执行细则

日期：2026-10-11。本文件实现已冻结验证v1中的风险训练/验证步骤，不更改其方法、目标或预算。评测与告警校准尚不执行。

先核对数据绑定、预测器配置/结果/审核/阶段冻结及所有权重SHA，再保存本阶段源码和依赖SHA。读取门仅允许risk_train与risk_validation完整24站切片；禁止预测分区、校准、评测以及完整速度矩阵读取。记录实际HDF5索引和逻辑访问。

每个分区本地构造12步历史、3步预测连续窗口；时间缺口两侧不能拼接。此处连续性仅使用时间戳元数据，在线分数不按未来速度或有效性过滤。监督再要求t−1至t+4六个原始读数自然有效且整个历史/监督连续、在本分区。边界及缺口附近不能确定Z的样本剔出监督池，仍保存所有合法预测起点的在线分数。后续事件计分须按时间缺口分段，不能把相隔的起点当作相邻5分钟。

冻结预测图、均值/尺度、三份TCN权重与12组故障。故障日期以整个数据D0为基准，不在风险分区重置轮换。每情景重新从可见历史推理；不调用旧全文件load_data或旧METR-LA预测缓存。特征沿用已冻结51维实现。

三情景共享六读数监督池；训练池拼接后求51维和一维特征均值/标准差，尺度下限1e−3，验证不得参与。Y/Z分类均不加类别权重。所有线性模型采用原LBFGS三alpha；分组不足100行/仅一训练类别/无验证时回退全局，记录原因。选定alpha最大绝对梯度须≤1e−4，否则阻止进入校准/评测。

持续低速MLP及起点MLP各训练202/203/204，复用原fit_uniform：1350次Adam更新、batch4096、有放回抽样，225/450/900/1350验证并选最小自身目标BCE。实际Adam.step计数，保存初始化与抽样索引SHA；同种子两监督必须一致。集成取三种子概率平均，不挑最好种子。

验证报告按Y和Z分开列BCE/Brier；不跨两监督比较BCE，不用验证分类损失替代事件服务指标。保存全部七方法在训练/验证上的分数，无阈值选择、无事件评测。独立审核重建标签、归一化、预测/特征抽样、全部分数、选择/收敛/预算及输入边界；完成后另存风险阶段冻结，不覆盖原设计或预测阶段冻结。

中断后仅在源码/配置完全一致且已完成文件SHA正确时复用已完成缓存/模型；不覆盖不完整权重。失败保留记录，不降低强基线收敛要求。实际原始速度访问仅两个风险分区。阶段冻结不是最终评测解封许可。
