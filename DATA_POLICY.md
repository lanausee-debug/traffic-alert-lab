# Data scope

Included: code, aggregate experiment statistics, protocols, plots of aggregate results, provenance hashes, and a randomly initialized synthetic tensor lesson.

Excluded: raw HDF5, model weights, prediction/feature caches, actual station time-series windows, thesis Word/PPT artifacts and private account information. The older 18-window local teaching demo is not in this package.

Obtain PEMS-BAY independently from the upstream DCRNN data instructions: https://github.com/liyaguang/DCRNN#data-preparation . This project does not assert authorization to repackage those dataset files. An upstream software license is not used here as a dataset redistribution grant.
